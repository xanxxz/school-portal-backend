# School Portal Backend

## Описание проекта

**School Portal Backend** — серверная часть школьного портала, разработанная на Node.js с использованием TypeScript.

Backend обеспечивает работу образовательной платформы: управление пользователями, курсами, расписанием, заданиями и учебными данными. Проект служит основой для масштабируемой школьной информационной системы.

Архитектура ориентирована на расширяемость, поддержку ролей пользователей и интеграцию с frontend-приложением.

---

## Назначение проекта

Основная цель backend-сервиса — обеспечить стабильную и расширяемую серверную инфраструктуру для школьного портала.

В рамках проекта реализуются:

* REST API для frontend-приложения
* управление пользователями (ученики, преподаватели, администраторы)
* работа с курсами и учебными материалами
* хранение расписания и заданий
* seed-инициализация базы данных
* подготовка к системе аутентификации и ролей

## Описание скриптов

### Запуск в режиме разработки

```bash id="d8m2kk"
npm run dev
```

Запускает сервер в режиме разработки с использованием `tsx`, позволяя выполнять TypeScript без предварительной сборки.

---

### Сборка проекта

```bash id="x1p6aa"
npm run build
```

Компилирует TypeScript-код в JavaScript (папка `dist`) для production-окружения.

---

### Запуск production-сервера

```bash id="r9c0zz"
npm run start
```

Запускает собранное приложение из директории `dist`.

---

### Seed-данные

```bash id="k5n3ff"
npm run seed
```

Запускает скрипт инициализации базы данных:

* создание тестовых пользователей
* добавление курсов
* заполнение расписания
* подготовка учебного контента
